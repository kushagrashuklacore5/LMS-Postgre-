# Core5 Academy help: index

This help explains how to use the Core5 Academy LMS **through its screens**: where things are, which buttons to click, and what to do when something goes wrong. Every document covers one task or feature and says which role it is for.

Numbers such as "how many students" are **not** written in this help. They are live and change; the help says **where** to see them.

## Recommended order for setting up a new school (Admin)

1. **Add Teacher**: add the teachers.
2. **Classrooms → Create Classroom**: each class needs a class teacher.
3. **Add Student** or **Import Students**: add the students into their classes.
4. **Courses → New course**: create courses for the classes, for all students or for selected students.
5. **Fee Structure**: set up the fees.
