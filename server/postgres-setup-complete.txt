STEP 1: INSTALL POSTGRESQL
==========================
Choose one option:

Option A: Download from website
1. Go to: https://www.postgresql.org/download/windows/
2. Download and run installer as Administrator
3. Remember your postgres password
4. Default: localhost:5432, user: postgres

Option B: Use Chocolatey (requires Admin)
1. Open PowerShell as Administrator
2. Run: choco install postgresql

Option C: Use Docker (requires Docker Desktop)
1. Install Docker Desktop
2. Run: docker run --name postgres-db -e POSTGRES_PASSWORD=postgres -p 5432:5432 -d postgres:15

STEP 2: CREATE DATABASE
========================
Open pgAdmin or psql and run:
CREATE DATABASE lms_database;

STEP 3: CONFIGURE ENVIRONMENT
=============================
1. Copy server/.env.postgres-ready to server/.env
2. Update PG_PASSWORD with your actual PostgreSQL password
3. Ensure USE_POSTGRES=true is set

STEP 4: RUN MIGRATION
=====================
cd server
node quick-migrate.js

STEP 5: VERIFY MIGRATION
=======================
1. Start backend server
2. Check for "Using PostgreSQL database" message
3. Test all CRUD operations
4. Verify data integrity
